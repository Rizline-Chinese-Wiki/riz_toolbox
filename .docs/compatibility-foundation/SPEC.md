# Specification: compatibility-foundation

## Lifecycle

保留依赖排序、失败回滚、级联停用与主线程约束，增加持久于本次进程的启用意愿。注册与尝试启用分离。若必需能力不可用则处于等待状态并保留原因；能力注册或撤回后统一 reconcile 所有插件。若插件主动被停用，之后能力就绪不能重新启动它；若回调故障，不能每帧自动重试故障插件。依赖撤回时先停用依赖者。

测试：能力晚就绪启动非示例插件；用户停用等待者；能力撤回和恢复；故障不循环重试；保留原有依赖、回滚和事件测试。错误返回 OperationResult 或状态原因，本地 API 无 HTTP 状态码。

## Ownership

GetService 返回当前启用作用域的服务视图。面板、资源覆盖、扩展点订阅由服务包装自动登记。作用域失效后旧服务、句柄及回调均不得继续产生游戏改动；资源 ID 使用插件命名空间防碰撞。取消订阅和逆序释放应幂等。插件自有配置只访问本插件配置文件，提供默认值、原子保存和错误原因。

测试：省略 Own 的面板/覆盖也会自动释放；缓存服务在停用后失效；跨插件面板名称不冲突；清理异常不阻断其余清理；非法配置名拒绝、原子读写可复现。

## Extension-points

提供具名、有版本的强类型扩展点描述、查询和注册机制。适配器提供目标和调用；插件仅订阅已声明目标，使用普通数据对象，不获取 native 指针。一个游戏接入点由适配器统一持有，多个插件订阅不重复打补丁。处理顺序按优先级及稳定注册顺序；异常归属到插件并触发宿主管理的停用；停用后自动撤销订阅。首批使用观察型 before/after 语义，明确不支持的参数/返回值修改；禁止把未实现的任意原生函数 patch 宣称为通用 Hook 能力。

测试：同目标多插件顺序；移除一个其余继续；异常不阻断其他插件；类型/版本不符拒绝；不存在目标返回原因；真实事件由实际游戏接入发布。

## Plugin-packages

每个插件包是 mods 下独立目录，含 plugin.json、入口 DLL 和私有依赖。清单包含 id、version、entryAssembly、entryType、SDK 范围、依赖与必需能力。加载代码前校验路径与元数据；入口仅加载一次。每包独立 AssemblyLoadContext，SDK 精确共享宿主程序集，禁止包内替换 SDK/Core/运行时组件；私有依赖只从本包解析。清单与 IRizPlugin.Manifest 必须一致。目录枚举顺序确定，坏包只影响自身。兼容旧平铺 DLL 时必须明确标为 legacy 且不承诺依赖隔离。

测试：两个同名不同版本私有库共存；共享 SDK 类型身份；缺依赖、清单错误、路径穿越、入口类型不符、ID/版本矛盾和重复 ID 均给出独立诊断。

## Adapter

拆分 Runtime（IL2CPP API 与原生入口）、Adapter（游戏符号/服务/事件/版本）和 Loader（组合/插件发现/命令诊断）。构建配置以指纹选择，Adapter 具备稳定接口，可集中维护符号和能力探测。缺少可选目标只关闭对应能力；缺少启动关键目标则停止适配并写原因。统一主线程 tick，避免对全局 runtime_invoke 的每次调用重复做字符串解析。真实开局/结算接入使用验证后的类型和签名，不能由历史分数变化伪造单局事件。

测试：已知构建选择；未知构建拒绝；必需与可选符号缺失分别处理；静态/实例和签名校验；单局事件有实际游戏调用证据，无法操作真实游玩时单列未验收。

## Game-resources

增加真实游戏资源的可枚举具名目标，保留面板图标服务但分清能力范围。覆盖使用原资源基线、高优先级优先、相同优先级稳定顺序。任意层释放后恢复下一层，全部释放后恢复原资源。目标销毁/场景切换后不访问悬空对象，根句柄与替换对象按所有权释放。写入后读回确认实际生效。

测试：两个独立包覆盖同一真实目标；依次停用和重启，读回每层资源；目标失效或缺失返回原因；不得以工具自建图标替代真实游戏资源验收。

## Distribution-and-validation

构建输出真实分层程序集和独立样例包，安装器继续校验文件归属、哈希、待完成日志和越界路径。更新不得覆盖用户配置或静默保留已停用样例的旧启动路径。保留从 0.1 安装升级的验证。输出准确 SDK 文档、架构说明、任务状态和自动测试/游戏运行证据。

测试：全量构建与核心/适配/包隔离测试；安装升级、重装、卸载检查；原始 EXE 和 GameAssembly 哈希不变；验收记录分别标记自动测试、真实运行、未验证，不用接口数量代替完成。
