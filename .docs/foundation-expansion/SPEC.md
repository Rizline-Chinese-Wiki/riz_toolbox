# Spec: foundation-expansion

2026-10-28 当前约束：框架尚未发布，按最新设计统一 API、SDK、包格式和内部协议；宿主、原生组件、模板与插件使用同一候选的合同，接口调整后同步更新并重新编译。旧 SDK 二进制、旧构造签名、历史协议和旧候选包的向后兼容不属于当前验收范围，不为其增加兼容层。历史包的验证记录只证明当时的实现，不继承为新合同的验收。当前组成部分之间的真实 ABI 一致性、游戏版本指纹、线程和资源生命周期校验仍需保证。性能优化及新性能基准后置，当前先补齐功能。

本文件定义下一阶段的目标行为，不表示这些接口已经存在。每个 B 任务都必须交付可执行路径、失败分支与验证证据。错误为本地结果，不使用 HTTP 状态码；下面的错误代码属于拟议的新结果契约，B03 实施前不可写进现有接口说明。

## B01 Gameplay closure

已完成本轮准备：Boolean 修复已安装，包哈希一致；原始游戏二进制不变。仍须从实际局状态取得开始，不能用进入 Level 场景替代已经开始，也不能在结算后补造一条开始事件。

如果检测到真实开始边沿，创建 RunId；同一控制器重复观察不重复发出；同谱面重试创建新 RunId。结束、失败与主动退出用明确不同的原因表示；没有开始证据的结果保留为未关联结果，不能宣称成对成功。初始化时已有结算只建立基线。缺失标志或接入失效返回 `CapabilityUnavailable`（“游玩生命周期暂不可用”），记录所缺符号/状态，不静默报可用。

验收：真实正常结束、失败结算、重试、暂停恢复、提前返回各有证据；有效局的开始和终止共享 RunId、谱面一致；停留结算页不重复；进入场景但未开局不发开始；原始复现日志与修复后日志分别保存。只有准备步骤完成不勾选 B01。

## B02 Native runtime

NativeRuntime 统一处理一字节 Boolean、指针、标量、枚举、字符串、数组与已知结构体；字段和方法先验证类型、静态性、参数方向及返回布局。缺少可验证布局时返回 `UnsupportedSignature`（“该签名尚未支持”），不得猜偏移或用一个泛型 Marshal 包办所有类型。

对象跨调用存活必须有根或受验证的句柄；对象失效返回 `TargetExpired`（“游戏对象已失效”）。Unity 操作只在已验证线程执行；Native 回调边界捕获托管异常，委托和跳板保持存活。C++ 直接调用、泛型共享、值类型返回、ref/out 分别登记支持范围，未知组合禁止启用对应写操作。

验收：Boolean 周边非零字节回归、各受支持布局的往返/拒绝测试、GC 后引用有效、失效句柄和错误线程拒绝；本机游戏实际调用和异常路径证据；运行时/适配器以外不能出现 IL2CPP 指针解引用。

## B03 SDK contracts

公共类型只含合同明确的 DTO、ID、不可变快照和受控句柄。以当前源码定义程序集身份、接口成员、构造参数和结果字段；需要调整时直接统一修改宿主、SDK、模板与测试。结构化结果明确代码、消息、能力/目标和可重试性，不保留旧记录构造或转换适配作为验收条件。

插件使用当前候选提供的 SDK；清单范围、实际共享程序集身份、服务类型和包格式均按当前合同检查。范围不匹配返回 `SdkIncompatible`（“插件需要其他 SDK 版本”）；其他错误合同按实际加载或服务诊断清楚拒绝，不以版本号相同推定二进制/API 正确。实验能力必须单列版本且显式查询，不伪装稳定支持。公开每项操作的线程、时间精度、清理责任、是否修改游玩和支持场景。

验收：当前 SDK 编译的独立插件经当前正式加载器和宿主运行；程序集、清单、服务与结果合同一致；错误范围、类型身份、接口或包格式独立诊断并拒绝，不能影响其他插件；未知枚举值按当前合同拒绝或明确保留为未知。模板和正式 SDK 文档只描述已有实现及对应验证范围。

## B04 Package lifecycle

在已实现的私有依赖隔离之上扩展可选依赖、显式冲突、加载顺序约束与持久启用意愿。必需依赖不存在或范围不匹配时等待并报告 `DependencyUnsatisfied`（“依赖未满足”）；可选依赖缺失时允许启动，作者可查询；环与互斥冲突在启用前给出完整路径，结果不随目录枚举变化。

停用依赖者先于提供者。配置迁移失败保留原文件，返回 `MigrationFailed`（“配置升级失败，原文件已保留”）。启用时事务性登记资源，失败全部撤回。磁盘更新需要重启时明确提示；包更新不得绕过安装归属和哈希检查。

验收：必需/可选依赖、版本不匹配、环、冲突、晚就绪、显式停用跨重启、启用异常回滚；同名私有 DLL 继续隔离；坏包和迁移失败不影响其他包。

## B05 Scopes and scheduling

扩展现有启用作用域，支持场景、单局及显式任务子作用域。父级结束先使服务失效，再取消任务/移除回调，最后逆序释放资源；每步幂等，清理失败继续释放其余资源。已失效的服务返回 `ScopeExpired`（“本次启用或场景已结束”）。

调度区分已验证的更新阶段；若没有实际 LateUpdate 等入口就不宣传该阶段。后台任务使用普通快照，不碰 Unity 对象；结果入队前和执行前都检查作用域代次。队列满返回 `QueueFull`（“主线程任务队列已满”），取消、超时和正在执行分别处理，禁止同步等待造成主线程死锁。

验收：停用后队列任务无副作用；场景切换和重新启用不接收旧结果；取消只完成一次；错误线程失败；批量任务不饿死游戏帧；回调中停用自身/依赖者无重入破坏。

## B06 Adapter capabilities

保留构建指纹，增加内部适配模块清单：模块 ID、所需符号/签名、依赖能力、可用场景、验证级别和降级原因。模块只负责一组能力，不向 Loader 写业务分支。能力按操作分细，如 `read/observe/override/control`，同时具有版本和可用性代次。

关键入口不匹配则停止该构建适配；可选目标缺失只撤回相关能力；暂时对象未就绪标为等待，场景变化或有界退避后重新探测；确定不支持的目标不每帧重试。查询返回 `UnsupportedBuild`／`CapabilityUnavailable` 及具体原因。跨版本字段差异在绑定模块处理，不能只改哈希绕过验证。

验收：已知/未知构建、歧义签名、可选缺失、对象晚就绪、能力撤回/恢复；旧服务失效；探测结果含构建与模块版本；无游戏依赖的 Core 测试无需启动游戏。

## B07 Hook broker

新增内部 HookBroker：适配模块声明精确目标、ABI、允许阶段与变更策略，Runtime 只维护一次实际挂接，Core 分发多插件订阅。精确方法拦截必须证明方法实际执行路径会经过该挂接点，不能把 runtime_invoke 的全局桥等同于拦截全部游戏方法。

观察点默认只读。仅已验证的目标可暴露参数变换、返回值变换或跳过原调用，分别声明；不支持的请求返回 `MutationNotSupported`（“该目标不允许此类修改”）。观察顺序按优先级和注册序；可变请求统一交给 B08，不允许插件各自修改同一原生地址。原调用恰好一次，跳过策略被明确采用时为零次；重入与异常路径规定上下文是否继承。

停用撤销逻辑订阅；原生跳板存在在途回调时不能释放。初期保留进程级跳板，空订阅时直通，不承诺原生卸钩热替换。高级接入包通过版本化 Adapter 扩展契约登记新目标，经相同探测与仲裁，不将任意写内存接口暴露为普通 SDK。

验收：两个插件共享一个真实目标；优先级、重入、回调异常、停用中的回调与原调用计数；各类受支持修改分别真实验证；拒绝错误签名和未授权策略；确定性状态回放不能代替实际挂接证据。

## B08 Mutation coordination

统一修改键为“语义目标＋属性/操作＋对象代次”。别名归一到同一目标。每个目标显式选择：优先级覆盖栈、有序纯变换链、独占租约或可证明的合并策略；不能把所有玩法命令都塞进颜色覆盖栈。相同优先级沿用稳定注册序，并在接口中说明最后覆盖者。

独占冲突返回 `Conflict`（“目标已由其他插件控制”）并列出所有者；变换结果非法时拒绝该次变更并隔离故障提供者。游戏自身修改基线时按目标策略更新原值或声明独占，不盲目恢复陈旧状态；对象销毁时结束对应租约。支持列出当前持有者、候选值与胜出原因。

验收：两个/三个插件交错启停、同优先级、别名冲突、故障中途回滚、游戏自身更改、对象销毁重建；只恢复仍属于本租约的修改；无法撤销的命令单列不提供假 Dispose 回滚。

## B09 Lifecycle events

建立场景代次、会话、RunId、暂停/恢复、重试、完成/失败/取消的统一事件模型；事件区分直接回调与采样推断并说明时间精度。初次接入只报告当前快照，历史结果不冒充新事件；RunId 为空时明确未关联。快照与事件携带同一修订序号，订阅初始快照和后续事件没有间隙或重复。

监听者异常归属插件，其他插件仍收事件；生命周期中的资源变更在确定的边界生效；旧场景消息不能更新新场景状态。不可观察的细分状态返回 `ObservationUnavailable`（“该状态目前无法可靠观察”），不合成虚假的暂停或取消事件。

验收：B01 全部流程，加快速重复进入、初始化位于结算页、插件中途启用、连续同谱面、退出时的迟到结果；事件序列符合契约且诊断可解释丢弃原因。

## B10 Data services

扩展曲目、谱面元数据、难度、最佳成绩、当前局结果和设置的只读快照。字段标注单位、来源、是否原始值和可空原因；未知时间不能伪造 PlayedAt。使用稳定内容 ID、来源命名空间、修订号；分页与缓存不会把后台工作变成 Unity 后台读。

就绪时返回一致快照；未就绪返回 `NotReady`（“游戏数据尚未加载”）；失效缓存明确标记陈旧或返回错误，不能静默充当最新数据。读取、导出和写入能力分开；批量读取设数量/字节上限并可取消。

验收：444 条现有样本回归、空集/缺字段、同名不同 ID、内容刷新、局中与结算字段一致、跨页同一修订、取消；不以最佳成绩变化推断单局结果。

## B11 Gameplay primitives

分别提供游戏/谱面时间、真实单调时间与音频 DSP 时间的读数和映射；暂停、倍速、偏移、延迟的含义独立。判定事件来自已验证调用点，复制音符身份、判定、时间偏差及单位；禁止以 250 ms 轮询近似逐音符判定。

控制原语按暂停/恢复、重试、速度、定位等逐项探测。支持且满足前置状态才执行；不支持返回 `OperationUnsupported`（“该控制尚未适配”）；状态不允许返回 `InvalidGameState`（“当前阶段不能执行”）；速度/位置等相互影响操作需 B08 独占或验证过的事务，失败不留下半重置局。

影响玩法的控制显式记录本局修改上下文，接口文档说明对游戏本地结果和提交路径的已验证行为；相关行为尚未核实的控制保持实验且不可宣称可用于正式结果流程。

验收：时钟暂停/速度变化/恢复、不同刷新率、判定顺序及计数与游戏结果比对、无漏重计；每个控制各测有效/非法状态、冲突、失败与撤销边界。无需交付完整练习 Mod。

## B12 Object targeting

提供语义目标登记与受控查询：资源 ID、场景挂载点、组件角色、内容 ID 优先于路径/名字；实例 ID 只用于会话内诊断。每个句柄包含对象代次，场景或对象重建失效；需持续绑定时由宿主重新解析并生成新租约。

唯一匹配则绑定；零匹配返回 `TargetMissing`（“目标尚未出现”）；多匹配返回 `AmbiguousTarget`（“目标不唯一”），不能随便取第一个。缓存随场景及对象变化失效；全场景扫描限频，不为每个 Mod 各扫一遍。

验收：同名对象、多场景、销毁后地址/实例 ID 复用、对象重建、延迟出现、模板与活跃实例区分；跨场景无悬空引用；绑定别名共享 B08 仲裁。

## B13 Visual resources

建立插件资源提供者和统一租约，按颜色、Texture、Sprite、Material 参数、字体逐类开放。音符/轨道外观、相机和后处理参数作为独立语义目标逐项接入，不以支持普通 Image 推断它们已支持。来源为插件包或登记的数据目录；加载受大小/格式/内存预算限制，CPU 解码可后台，Unity 对象创建与赋值回主线程。引用计数区分框架创建和借用的游戏原始资源。

加载成功后才原子替换目标；解码/上传失败返回 `ResourceLoadFailed`（“资源加载失败，原资源保留”）；插件停用中完成的加载丢弃并释放；被覆盖的原资源在恢复完成前保持有效。持久覆盖意图可在对象重建时重新绑定，但不能复用旧对象句柄。

验收：每种开放类型都在真实游戏目标验证双插件覆盖、失败保留、停用恢复、场景切换、重复加载释放；不得以工具面板图标代替游戏皮肤目标。AssetBundle 等未接入格式登记不支持。

## B14 UI input navigation

提供有所有权的 UI 挂载点、基础控件、布局/缩放、字体/主题引用和页面/弹窗生命周期；提供输入动作登记、按键重绑、焦点栈及经过验证的游戏导航原语。键盘、鼠标、手柄分别声明可用设备与映射，屏幕/UI/游戏坐标转换写清单位和有效区域。具体页面和产品视觉由 Mod 作者实现。

输入冲突按上下文与焦点规则解决；文本输入与模态窗口应阻止对应快捷键穿透。全局、菜单、游玩输入分别声明范围；未验证的原始输入注入不冒充支持。目标页面不可达返回 `NavigationUnavailable`（“当前不能打开该页面”），输入动作重复或互斥冲突返回 `Conflict` 并列出绑定者。

验收：两个插件的面板/弹窗/快捷键并存、同名局部 ID、分辨率/DPI、切场景销毁、焦点归还、输入框输入、停用后无残留遮挡与回调；至少两个真实挂载点与一次游戏导航。

## B15 Audio and content providers

音频能力分为自有声音播放、游戏声音替换、混音参数及播放时钟，按目标支持范围暴露。曲目/谱面/封面/音频的本地提供者使用命名空间与稳定 ID，在内容解析边界注入，经格式版本和依赖验证后登记到内容服务；不要求实现编辑器或在线分发平台。

格式不支持或资源缺失返回 `ContentInvalid`（“内容或依赖无效”），整个内容条目不发布；重复 ID 返回 `Conflict`；提供者退出时已有局持有的资源继续到租约结束或按明确规则取消，不能立刻销毁正在播放的音频。内容引起的玩法/结果差异记录在 B11 的局上下文中。

验收：自有音频播放停止释放、真实游戏音频目标替换恢复、同名跨提供者内容、坏格式/缺资源、加载取消、局中提供者撤回；音频延迟和卡顿单独测量；只宣称已实际适配的格式和替换点。

## B16 Settings storage localization

插件配置添加 schema 版本、校验、迁移与变更通知；提供插件独立数据/缓存目录、原子写入、大小限制与只读游戏数据访问。可逆游戏设置修改使用 B08 租约；修改范围只限适配器已验证字段，不以任意文件写入伪装存档事务。语言键和资源引用使用插件命名空间，热切语言不要求重启插件。

JSON 损坏返回 `ConfigInvalid`（“配置无法解析，原文件已保留”）；迁移失败不覆盖原件；配额超限返回 `QuotaExceeded`；语言缺键按本插件后备语言回退；不支持的游戏存档操作明确 `OperationUnsupported`。日志与导出不默认打包账号信息或原始存档。

验收：旧配置升级、损坏配置、迁移异常、并发保存、路径/链接逃逸、满配额、语言切换、相同键跨插件；停用后租约式设置恢复，用户在租约期间主动修改的处理遵循目标基线策略。

## B17 Inter-plugin contracts

在依赖系统上提供版本化服务注册/查询、可选服务就绪通知和只读消息通道。公共契约必须具有受控共享类型身份，私有 ALC 中同名 Type 不能直接强制转换；首版优先 SDK DTO，额外契约包须显式版本、哈希与共享身份策略。

提供者就绪且满足当前声明的版本范围和共享类型身份时返回代理；不可用返回 `ServiceUnavailable`（“服务提供者未就绪”）；提供者停用后代理失效并通知消费者，硬依赖按拓扑停用，软依赖降级。调用异常正确归属提供者；请求大小、超时、线程与循环依赖有明确限制。

验收：使用当前合同的两包调用、声明范围匹配与不匹配、错误类型身份拒绝、供应方撤回再出现、软/硬依赖差异、重复服务、跨 ALC 契约、回调递归和异常归属；普通插件仍无需引用 Core/Runtime。不要求历史编译插件或旧服务协议继续运行。

## B18 Diagnostics and performance

提供按插件、能力、目标、RunId、场景代次过滤的结构化诊断；记录探测失败、等待原因、冲突持有者、挂接来源、回调次数/耗时、队列压力和资源计数。日志分级、轮转、限流；逐对象扫描日志默认调试级并聚合，不能把短时间日志增长当作正常验收。

建立无插件、空框架、两个探针、压力插件四种基线，记录机器、分辨率、帧率设置、采样时长、p50/p95/p99、分配和句柄数量。回调超预算先记录并按约定停用托管订阅，不能声称能强行中断同进程原生代码。首版预算需基线测得后写入版本化阈值文件，不凭空宣称已达毫秒目标。

验收：诊断能解释一次漏报/等待/冲突；慢插件、事件洪峰、循环日志、磁盘不可写、反复场景切换压力下可控；设置阈值后 CI 比较基线，20 轮启停/切换无单调资源增长；证据导出只包含所选会话与必要信息。

## B19 Distribution and conformance

构建产出可复现包、SDK 引用包、模板、能力清单、支持构建和迁移说明。示例改为小型契约探针，至少两个独立包验证共存；生产安装默认不启动颜色覆盖、导出和自退出测试，已有配置由显式迁移策略处理。

安装验证归属/哈希，更新中断可恢复，失败保留已知可用版本和原始配置；原始游戏二进制哈希不变。发布门槛为每个已宣称能力的正向、拒绝、冲突、撤销、版本与性能证据。无法完成真实流程的条目保留未验收，不用自动测试数量替代。

验收：当前 SDK、模板、宿主与原生组件组成一致候选，错误合同及混用组件明确拒绝；当前包安装替换/中断恢复/重装/卸载/用户编辑配置、未知游戏构建拒绝或关闭对应能力；正常结束/失败/重试/退出/暂停集成矩阵；干净环境按文档构建并装入游戏；完整支持表和限制与实际返回值一致。不要求跨历史 SDK/API/包/协议的运行兼容。
