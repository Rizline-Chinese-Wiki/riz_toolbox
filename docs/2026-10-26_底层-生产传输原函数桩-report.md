### F2/F3：准确前缀、活跃寄存器与真实机器回执

九个新 original 固定顺序为 Register、Remove、Consume、Pump、Drain、Callback、Yield、Dispatch、Batch。磁盘核验同时要求 baseline 与 original 的 prefix 字节等于固定 Unity 原件；每个 original 精确 10 字节尾跳，`RIP-relative MOV scratch,[continuation] / JMP scratch`。Callback 用 R10，其余八个用 R11；continuation 槽严格按九种顺序连续，位于可写且不可执行的数据区。实际 EXE 为 54 functions / 54 names，无转发标记。

Callback 的 17 字节前缀为 `MOV R11,RSP; SUB RSP,98h; MOV RAX,RDX; CMP [RDX+58h],RCX`。完整 body 后续继续用 R11 定位栈槽，不能沿用旧 MOV R11/JMP R11 模板。P0 通过 Capstone `regs_access()` 和显式寄存器、内存 base/index，核整个 Callback 无 R10/R10D/R10W/R10B 使用；P1 在自有真实 tail 中验证 R11 指向入口栈及独立栈写 canary。此 scratch 结论限定固定 body，不对其它版本或其它函数作通用许可。

自有 fixture 以同字节未拆分 baseline 为对照，实际计算返回值和输出槽；核四个 live GPR、RAX、高 EAX、原比较 flags、LastError、caller RSP 与八个非易失 GPR、栈 canary。Consume / Drain / Callback / Dispatch 两组输入均执行；最终自有 ASM 用 JNZ taken/not-taken 保存实际分支，MOV/JMP 保原 flags，不把调用方的期望值直接当观察结果。
