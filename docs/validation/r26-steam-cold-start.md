# Steam r26 冷启动实测

2026-11-27 在同一台 Windows 电脑上从 r24 Basic 升级到 r26 Basic，复核 22 个安装文件，67 个用户文件的 SHA-256 与升级前一致。r26 对应提交 `91960767`。

| 前 21 次适配器更新 | r24 | r26 |
| --- | ---: | ---: |
| 最长一次 | 57.316 秒 | 2.173 秒 |
| 单次最大托管分配 | 791,112,176 字节 | 7,717,096 字节 |

r26 的第 2 次更新已出现这两个峰值，到第 91 次更新时累计最大值相同，所以可以确定前 21 次的最大值。采集器没有恰好记录第 21 次更新时的中位数。两次启动的插件启用情况也有差异。这组数据描述两次实际运行，无法单独量出某一处代码改动的收益，也无法推算从 Steam 启动到主菜单可操作的时间。

第 2 次更新中，判定模块激活用时 1879.7 毫秒，分配 6,609,192 字节。现有日志只计整个模块。后续细分计时应覆盖 GameAssembly 文件校验、运行时符号解析、Hold 生命周期初始化和观察器注册，再依据实测决定优化位置。
