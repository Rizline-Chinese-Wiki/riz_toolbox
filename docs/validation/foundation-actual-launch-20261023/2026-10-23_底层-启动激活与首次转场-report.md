## Path

P-001，`path_type=callflow`。start：同一空闲五门宿主与真实根输入；goal：实际转场和原版初始化图核验后的 LOCAL ready。

1. bundle → prepared session → commit claim → 四池预留；每个未知交接由 owner 保留责任。（E-002，F-001）
2. prefab/globals/Awake window → inactive clone → 独立 controller 根 → 实际 setter 回执 → 捕获 scene origin。（E-001,E-002,E-003，F-002,F-003）
3. 单次 activation → `StartNextScene` 一次 → 实际新 AsyncOperation → loaded Level/async 清空/lock 清除。（E-001,E-002,E-003，F-002,F-003）
4. 宿主帧泵确认同 controller、六 globals、Start/getter/设置回执与 drain → PrepareCommit/CommitPrepared → 完成 pending handler。（E-001,E-002，F-001,F-003）
5. 真实结果缓存 → 先 publish presentation owner → 自建窗口 → 类型化命令回调/关闭 → 回调退出后 UI consumers ended。（E-001,E-002，F-004）

residual_risks：第 1–4 步尚无本批整链游戏执行；第 5 步不等于 active 原生消费者结束。相机/粒子/输入锁、完整 Retry/Return、所有资源退休与 Loader 准入继续缺失；发生未知清理时保留责任并拒绝再启动。
