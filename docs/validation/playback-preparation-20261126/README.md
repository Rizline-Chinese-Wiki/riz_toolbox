# 播放组件准备阶段的重复校验

一次安装需要准备 19 个普通播放组件。每个组件在保留入口和准备原始调用后都要验证当前映像和组件身份。现在同一个只读阶段可以共用这两项检查；下一次操作仍从头验证。

| 同一离线双映像用例 | r22 | 本次修改 |
| --- | ---: | ---: |
| 每个普通组件的完整映像校验 | 65 | 55 |
| 19 个组件的完整映像校验合计 | 1,235 | 1,045 |
| 19 个组件的整组校验合计 | 57 | 57 |

这项改动在该用例中减少了 190 次完整映像校验，约 15.4%。用例包含实际准备和提交各 23 次，最终完成启用。针对保留入口后、原始调用准备后、配置后及进入下一帧这四个时点分别改变输入，四个用例均在提交前拒绝继续。相关的 3 个 GetTime 用例和 5 个自制谱／官方谱安装顺序用例均通过。
