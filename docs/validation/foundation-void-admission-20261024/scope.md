# 本批范围与授权

用户明确允许恢复三个代理继续工作；本批按“先继续代码，实测稍后”执行。root是唯一构建者，源代码冻结后统一构建；不安装、不启动或操作游戏，不终止进程。共享工作树不提交、不推送、不清理。

原生void父入口增加有界Close/Verify/Release准入协议，关闭后新调用在原生层停车，已经准入的调用连同Enter/original/Exit完成后才签发凭据。同步同槽递归继续执行；在任意void回调中的自Close被拒绝。凭据绑定槽、全局代次与OS线程；错误或不确定结果不能自动打开已签发的门。

运行时提供独立可选接口和私有租约，保持现有观察接口与旧ABI。只在已验证的Closed/Active0状态使用凭据；首次写尝试或未知结果保留进程责任，Dispose不打开门。实际桥与真实Dobby的联合验证、独立native fixture和受控协议测试分别记证据。

该协议只覆盖已经安装的父入口之后的调用准入。它不证明首次父detour的安装安全，不发布生产mid patch，不证明实际IL2CPP监听图、GC、全run消费者结束或游戏验收。完整B01–B19仍按SPEC验收，仅B03整项/B18a子项已勾。
