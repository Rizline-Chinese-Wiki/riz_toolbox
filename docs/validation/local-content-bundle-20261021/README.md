# 本地内容原子组登记

2026-10-21。子代理只完成新增 SDK 接口后因额度中断；主代理实现事务、模块接线和回归。首轮 `regression.log` **48/48** 通过；随后补4项所有权/快照/有界读取检查，最终结果以本轮完整构建日志为准。

独立能力 `riz.content.local.batch` 和 `ILocalContentBatchProviderService` 不向旧接口添加必需成员。一个组为1..32个内容请求，共享一次发布修订；复制有界请求与依赖、验证格式/版本/重名/DAG、解析全部资源、检查累计额度后提交。组内前向依赖可用，环、缺依赖和重复依赖拒绝。作用域接管、取消、parser代次、外部依赖身份在提交前重新检查。单组失败不发布任何条目，不消耗发布修订。

组租约撤回先移除所有条目的可见性，再释放发布引用。已存在消费者依赖图继续保活；未释放资源继续占配额。parser撤回会整体撤回含图的组，避免只剩封面/音乐的半组；普通单条内容的已有行为保留。旧接口仍用于读取发布列表。

新增16项覆盖前向依赖、重复ID、缺失/版本/重复依赖/循环、解析失败、取消、作用域/parser/依赖撤回、消费者保活、整组撤回、保留配额、跨提供者命名空间、错误线程、Own失败/立即释放、Own取消、调用者修改数组与有副作用的Count。没有以此证明游戏能添加新歌曲或解析本地音乐/封面；那些接入仍缺。

按现有受支持 parser 的主线程 Dispose 契约清理图根；实际 GC/长期释放故障矩阵仍属于未验收 B02/B15。示例和格式限制见 `../../Audio-content.md`。
