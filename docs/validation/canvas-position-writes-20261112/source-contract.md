# Canvas position method contract

`ISeekCanvasPositionNativeProfile` exposes only TransformClass, GetLocalPositionMethod, SetLocalPositionMethod and VerifyCurrent. The production constructor takes NativeRuntime and supplies no object root, existing source capture or Hold instance. It verifies the pinned GameAssembly fingerprint/current mapped module, fresh exact declared method metadata and both complete 80-byte wrapper hashes at each VerifyCurrent. The two bodies are unchanged from NativeSeekRendererProfile; this package reads existing evidence and local files without executing or mapping the game.

The exact ABI is `Transform.get_localPosition() -> UnityEngine.Vector3`, RVA0x1561640, and `Transform.set_localPosition(UnityEngine.Vector3) -> System.Void`, RVA0x1561cd0. `InspectCanvasPositionMethod` permits only these names on the canonical Transform class and rejects static/abstract/generic/inflated or byref forms. Each lookup independently verifies current Vector3 code17/12-byte storage, exactly three declared nonstatic x/y/z fields at boxed offsets0x10/0x14/0x18, native value offsets0/4/8, canonical Single code12/4-byte storage and complete class/type/name/image/parent/lookup associations. These current exports run before checking cached Describe layouts, so a warmed cache cannot certify drifted widths, fields or byref metadata. The setter's Void result is also canonical and non-byref.

Both wrappers resolve a Unity internal call and invoke its pointer indirectly. Wrapper bytes/MethodInfo do not prove the resolved implementation, side effects, callback exit, inverse or complete Seek. Command/backend owners must retain independent exact Transform sources, compare requested and observed positions by raw Single bits, preserve slot/alias policy, guard callback boundaries and retain every entered write attempt/unknown cleanup responsibility. Full Seek remains disabled.

Reproduce the file-only contract from the project root with `C:/Python314/python.exe work/seek-canvas-position-native-20261112/verify-position-profile.py`. `position-profile-verification.json` records exact source/helper/evidence hashes and explicit false runtime/engine/admission claims. Builds and actual product tests are separate parent validation.
