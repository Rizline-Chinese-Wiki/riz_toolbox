`GameplayNativeBackend.CaptureSourceDescriptor()` already treats the descriptor provider as optional for independently rooted game fields. A provider exception yields null. `Prepare.VerifyCapture` previously classified every captured null as TargetExpired before its later NotReady branch; even an initially pending, unchanged graph could never reach NotReady. It now distinguishes captured null/current null from any loss or change of previously held authority. The former returns structured NotReady before provider entry; the latter remains TargetExpired. Native run/generation/graph mapping and repeated validation around provider preparation remain intact.

`GameplayService.Capture` separately terminates the exclusive control owner when descriptor availability changes without another graph/native generation change. It preserves the independent observation lifetime and last descriptor used only for successor detection. A pending lease cannot acquire a later descriptor's authority. Present changed descriptors continue through the existing generation transition. No public API, capability enablement, restoration, DSP schedule, pitch writer or Seek admission changes.
