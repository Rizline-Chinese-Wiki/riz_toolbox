# r27 Steam 冷启动实测

2026-11-27，Steam Basic 从 r26 升级为 r27。安装器逐一核对了 22 个包内文件与 67 个原有用户文件。测试使用提交 `9057d0c6` 的适配器。

首次采集在 Steam 启动选项窗口等待超时。第二次先启动采集器，再选择「玩 Rizline」。采到 31 份状态快照，部分修订之间有间隔。判定模块在宿主第 2 次更新时启动，用时 2365.4 ms，记录的分配量为 6611272 字节。

| 初始化步骤 | 本次耗时（ms） |
| --- | ---: |
| 指纹核对 | 134 |
| 解析并验证目标 | 16 |
| 后端建立 | 5 |
| Hold 生命周期 | 1 |
| Hold 停止观察 | 2135 |
| 其余观察器 | 71 |

`JudgementModule.TryInstallHoldStops` 对六个停止操作分别调用 `ResolveCoroutineStopHook` 和 `BindNativeOperationObservation`。2135 ms 是整个循环连同完成登记的耗时。现有采样无法区分方法解析、观察器绑定和具体操作各自的耗时。

本次实测覆盖启动。官方谱播放控制与本地谱结算另行验收。
