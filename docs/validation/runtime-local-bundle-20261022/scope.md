# 本轮范围

- auth：用户要求实现 PC 端兼容性底层，并明确允许恢复游戏实测和多代理协作。
- in_scope：用户桌面 riz_toolbox 源码、本地游戏 Rizline 已授权安装、独立原创测试资源、资源包责任及实际原生生命周期验证。
- network_profile：本轮构建和资源包验证使用本地缓存和既有 Steam 游戏；不向 QQ、GitHub 或其他人发送消息、上传或发布。
- completion_boundary：仅本轮资源包交付与证据完成；完整 foundation-expansion B01–B19 仍 active，仅 B03 整项和 B18a 子项已勾。
- exit_boundary：只确认游戏进程停止；未观察正常退出操作，不推断原因。
