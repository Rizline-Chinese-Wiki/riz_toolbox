# 本批范围与授权

用户要求继续完成 PC Mod 兼容底层，并授权多代理协作。最近明确安排为“先继续代码，实测稍后”；本批只实现和验证代码，不安装、不操作游戏 UI、不终止游戏进程。

目标为把上一批原生 listener 的三处 pre 与三处 post 区域接入固定版本的预初始化 producer，并让生产 C# 只读采用完整 V2 身份。旧 V1 布局保留并如实报告实际写尝试数；旧三写记录不能授权六区。RequestPlay、listener ledger 与全消费者退休的完成条件不因本批变更而放宽。

允许在独立测试进程以 DONT_RESOLVE_DLL_REFERENCES 映射固定 GameAssembly，检查实际内存发布和 OS 展开元数据；不执行任何游戏地址、IL2CPP init、目标 DLL 初始化或游戏导入。故障注入只修改这些自有隔离进程中的映像和分配块。测试脚本只在明确创建的子进程句柄上执行超时终止。

固定输入：GameAssembly SHA-256 `853d6530d694079cf1cd596b3362c5bcb647da211541a008d7463999bc5b1b79`；Dobby SHA-256 `8015de7d867245a1095d13947a63763878e4cf5fd3d3089b63cc39200b055ded`。不扩大支持版本，不修改原游戏文件，不提交或推送。

工作树为桌面 riz_toolbox；所有代理共享 checkout，root 为唯一构建者。具体运行结果以本批日志、JSON 和冻结档案为准，本文件只说明范围。
