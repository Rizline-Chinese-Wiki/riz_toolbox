# 固定系统 WinHTTP 转发：实现与独立宿主验证

本批承接 PC 模组公共底层开发及自有宿主测试授权，继续完整 B01–B19。允许新增固定转发组件并运行自己构建的宿主；真实游戏实测仍按用户“先继续代码，实测稍后”暂缓。

范围为 Doorstop 下新增的 C/header/MASM 转发组件、独立测试宿主与 Importer、构建及父验证器。系统模块固定为当前 64 位 Windows 的 System32/winhttp.dll，读取实际路径、文件身份、PE 和 hash；在明确的初始化回调外加载并调用本机系统四个 API。未使用 IDA 后端，PE 核验采用冻结源码的离线解析器，不将其称作反编译。

只进行 NO_PROXY 会话创建/关闭、当前代理设置的只读查询，以及无 PAC/WPAD 的本地参数拒绝对照。不调用 Connect/OpenRequest/SendRequest，不请求游戏服务器，不修改代理或注册表设置；没有网络流量捕获，不能据此断言系统内部零流量。用户设置字符串不落原文，只比较进程内加盐摘要、长度和空值。

实际 Importer 初始化工作负载与 loader 外显式调用分开记录。本批证明预先解析的四个转发槽及其 typed ABI，不授予 WinHTTP 任意函数在 DllMain 内安全的结论，不声称真实游戏的早期首次发布或 V4 凭据已经完成。

构建由 root 唯一执行；代理分别维护解析器、宿主和独立核验器。613 项声明源以此前604项为基线，预期只新增9项，历史归档不改。每个宿主是独立的自有进程，父持只读输入句柄、有限超时并记录实际退出；只有正式命令的真实终态与逐项原件核对后才能出成功报告。初始编译或运行失败按原件保留。
