# 托管插件加载预览

这部分是面向协作开发的独立 .NET 托管组件，不是可安装的游戏运行时。它只依赖公开 SDK。

- `DiscoverDirectory` 读取插件清单和托管程序集元数据，不执行插件构造函数。
- `LoadDiscovered` 在宿主明确选择后加载本机信任的插件，验证文件快照及 SDK/依赖身份。包各自使用可回收的加载上下文；包内更新需要重启宿主，不自动覆盖磁盘文件。
- 这是代码组织和依赖隔离，不是安全沙箱。不要加载来源不明的二进制；不包含游戏进程接入、原生适配、游戏资产、上游二进制、运行期游戏服务或完整插件启停调度。

## 从干净目录验证

需要 .NET 8 SDK；托管库面向 `net6.0`，测试运行在 `net8.0`。测试程序集由仓库内的 C# 源码构建，不需要游戏或第三方测试包。

```sh
dotnet run --project tests/RizToolbox.Hosting.Tests/RizToolbox.Hosting.Tests.csproj -c Release
```

测试覆盖只读发现、延后实例化、清单和依赖校验、相互独立的插件包、失败隔离及文件变化诊断。游戏内生命周期和兼容性未验证。
